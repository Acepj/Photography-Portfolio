"""# Amorth Maria Photography

An elegant and responsive photography portfolio website designed to showcase photographs, featured moments, photography categories, and booking information.

## 📸 About the Project

**Amorth Maria Photography** is an editorial-style portfolio website that presents photography work through a clean, modern, and visually focused design. The website highlights different photography disciplines while providing visitors with information about the photographer and a contact section for inquiries.

## ✨ Features

- Responsive navigation bar
- Editorial-style hero section
- Featured photography carousel
- Gallery section with image cards
- Image preview modals
- Photography categories section
- Categories offcanvas panel
- About the photographer section
- Frequently Asked Questions (FAQ) accordion
- Contact form layout
- Booking availability alert
- Social media icons
- Responsive layout for desktop, tablet, and mobile devices

## 🖼️ Photography Categories

The website includes the following categories:

- Portrait
- Fashion
- Landscape
- Architecture
- Street Photography
- Travel
- Editorial
- Lifestyle
- Events
- Creative Photography

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5.3.3
- Bootstrap Icons 1.11.3
- Google Fonts
  - Playfair Display
  - Inter
